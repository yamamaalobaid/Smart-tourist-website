# Damascus Tourism Guide - Frontend

تطبيق ويب مميز لاستكشاف الأماكن السياحية في دمشق

## المميزات

- 🎨 تصميم حديث وجميل
- 🔍 بحث وتصفية الأماكن
- ⭐ تقييمات والمراجعات
- ❤️ قائمة المفضلة
- 📱 متوافق مع الهواتف الذكية
- 🌐 واجهة ثنائية اللغة (العربية والإنجليزية)

## التثبيت

```bash
cd frontend
npm install
```

## التشغيل

```bash
npm run dev
```

سيتم فتح التطبيق على `http://localhost:3000`

## البناء

```bash
npm run build
```

## الهيكل

```
src/
├── components/      # مكونات React مشتركة
├── pages/          # الصفحات الرئيسية
├── services/       # خدمات API
├── store/          # إدارة الحالة (Zustand)
├── App.tsx         # المكون الرئيسي
├── main.tsx        # نقطة الدخول
└── index.css       # الأنماط
```

## الصفحات

- **الرئيسية** `/` - عرض الأماكن المميزة والمعلومات الأساسية
- **الأماكن** `/places` - قائمة كاملة بالأماكن مع التصفية والبحث
- **تفاصيل المكان** `/places/:id` - معلومات شاملة عن مكان معين
- **تسجيل الدخول** `/login` - صفحة دخول المستخدم
- **التسجيل** `/register` - إنشاء حساب جديد

## التكنولوجيات المستخدمة

- React 18
- TypeScript
- Tailwind CSS
- React Router
- Axios
- Zustand
- Lucide React Icons

## الاتصال بـ Backend

الـ API متاح على `http://localhost:5000/api`

يمكن تغيير الـ URL في `src/services/api.ts`
